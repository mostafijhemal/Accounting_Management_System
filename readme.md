## 🚀 About the Project

Traditional manual accounting systems are time-consuming, insecure, heavily dependent on individuals, and prone to calculation mistakes. The **Accounting Management System** solves these challenges by offering an easy-to-use, comprehensive, and affordable solution to handle daily financial operations, manage accounts payable/receivable, track transactions, and generate instant financial statements (Trial Balance, Income Statement, and Balance Sheet).

---

## 🛠️ Key Features & Modules

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>1. User Management</h3>
      <ul>
        <li><b>Create & Remove Users:</b> Admins can manage system access and accounts seamlessly.</li>
        <li><b>Access Control:</b> Role-based permissions ensuring users only perform authorized operations.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h3>2. Chart of Accounts</h3>
      <ul>
        <li><b>Account Head Management:</b> Create, update, and organize account heads for structured bookkeeping.</li>
      </ul>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>3. Transactions</h3>
      <ul>
        <li><b>Bill Management:</b> Manage bills, payments, and financial inflows/outflows.</li>
        <li><b>Voucher System:</b> Custom check, approve, and display voucher types.</li>
        <li><b>Account Closing:</b> Handle daily and yearly financial closing operations.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h3>4. Comprehensive Reporting</h3>
      <ul>
        <li><b>Account Ledger:</b> Detailed tracking of individual accounts.</li>
        <li><b>Trial Balance:</b> Verify mathematical ledger accuracy.</li>
        <li><b>Income Statement & Balance Sheet:</b> Automated financial summaries.</li>
      </ul>
    </td>
  </tr>

## 🧰 Technology Stack

* **Front-End:** HTML5, CSS3, JavaScript, jQuery, Bootstrap Framework v3.4
* **Back-End:** PHP (Object-Oriented Programming), CodeIgniter Framework v3.1
* **Database:** MySQL
* **Development Environment:** XAMPP Server, Adobe Dreamweaver

---

## 🔄 System Architecture & Lifecycle

The project follows a standard Software Development Lifecycle (SDLC) approach:
1. **Initiation:** Project planning, activity scheduling, and resource task allocation.
2. **Execution (Analysis & Design):** Requirement gathering, feasibility studies, and relational database schema design.
3. **Implementation:** Built following the **MVC (Model-View-Controller)** architectural pattern to ensure modularity, separation of concerns, and system maintainability.
